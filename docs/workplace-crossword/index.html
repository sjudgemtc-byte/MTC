Workplace Digital Words Crossword

Practise common digital literacy words used in class, work and online forms. Type one letter in each square, then check your answers.

Classroom rule: use the clues only. Do not type real passwords, private account details, student numbers, banking details or personal identity information.

Student activity

Complete the crossword

Use the clues on the right. If you get stuck, ask for a hint or work with a partner.

Support option
  • Read each clue aloud.
  • Say the word before typing it.
  • Use the first letters if you need help starting.
Clues

Across

  1. A secret word or phrase used to sign in.
  2. A message sent online, often for work or class.
  3. A file sent with an email.

Down

  1. Use Google or another tool to find information online.
  2. A page open inside a web browser.
  3. A short online conversation or message exchange.
Extension

Choose two words and write one workplace sentence for each word.
