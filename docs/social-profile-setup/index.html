Online Safety And Employability

Social Profile Setup Practice

Practise setting up a social media-style profile in a safe simulator. This activity uses common ideas from X, Facebook and LinkedIn, but it does not create a real account or publish anything online.

Classroom rule: use fictional or low-risk details. Do not type a real date of birth, home address, phone number, password, banking details, Medicare details, passport details, private family information, or workplace confidential information.

Activity steps

Low-stakes practice: this page keeps everything in the browser. It does not send the form anywhere and it does not publish a profile.
Step 1

This activity builds skills in online forms, profile setup, privacy choices, digital identity, security awareness, review before posting, and plain English workplace communication.
