# MTC Daily Assistant

Small local prototype for Simon's MTC daily workflow.

## Version 0.1

This first version is deliberately simple:

- Start day checklist
- Main focus field
- Follow-up list
- Working note area
- Close-off journal text generator
- Browser-only saving through local storage

It does not read official records, send messages, upload files, or edit MTC documents.

## Open

Open `index.html` in a browser.

## Next possible additions

- Load a daily journal file
- Save a close-off entry directly into a journal file
- Import yesterday's follow-ups
- Add student-note templates
- Add optional AI drafting once the basic workflow feels right
